# Bo Dong — personal homepage

Static personal homepage for https://dongbo910220.github.io/.

Built with HTML, CSS, JavaScript, and local image assets. No package installation, backend, analytics, or external font service is required.

## Preview

Open `index.html` directly, or use a local static server:

```sh
python3 -m http.server 8767 --bind 127.0.0.1
```

## GitHub Pages

The intended publishing source is the `main` branch at the repository root (`/`). `.nojekyll` keeps the site as plain static files.

The page contains open-source contributions, the three most recent employment records, education, the provided portrait, and contact links.
