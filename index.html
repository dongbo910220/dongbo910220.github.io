  • Distributed VAE Patch Parallelism

    PR #756

    Implemented spatial parallelism for VAE decoding with automatic tiled/patch routing, distributed tile decoding and blending, halo-based core-region decoding, and improved multi-GPU load balance.

    At 1536 resolution: 1.72× inference speedup and 24% lower memory usage.

    Technical details

    Designed and implemented spatial parallelism for VAE decoding, with automatic routing between distributed tiled and patch decoding paths.

    • Large-image decoding. Distributed overlapping tiles across ranks, decoded them in parallel, restored the original grid order, and applied boundary blending, cropping, and stitching.
    • Small-image halo decoding. Partitioned non-overlapping core regions, extended neighboring latent values as halo context, decoded independently, and gathered only the cropped core outputs. Added tile-allocation offsets to improve multi-GPU load balance.

  • DiT Tensor Parallelism

    PR #735

    Implemented tensor parallelism for Z-Image Turbo and other models by adapting their Attention and MLP modules for distributed execution.

    Latency and peak memory both decreased by 22% in the reported test.

  • Ulysses Anything Attention (UAA) Sequence Parallelism

    PR #1379

    Extended Ulysses sequence parallelism beyond divisible attention-head counts and equal-length sequence shards. Implemented head padding and output restoration, plus variable-split AllToAll for Q/K/V and reverse output resharding, supporting more parallel degrees and input shapes without communication-only sequence padding.

    Technical details

    Implemented the UAA extension on top of classic Ulysses sequence parallelism. The original implementation relied on evenly partitioned attention heads and equal-length AllToAll communication: the number of attention heads had to be divisible by the parallel degree, and every rank had to hold a sequence shard of identical length. When a model’s head count or an input sequence did not satisfy these conditions, the original resharding path could not execute directly, limiting support for different parallel degrees and input shapes. Extended the attention resharding path to broaden sequence-parallel support for diffusion models.

    • Attention-head adaptation. Implemented head padding, parallel computation, and output restoration for configurations whose head count is not divisible by the parallel degree. Heads are padded to a multiple of the parallel degree and trimmed back to the original count after computation, supporting previously restricted parallel configurations without changing the model’s head configuration.
    • Variable-length communication and data resharding. Implemented variable-split AllToAll to handle unequal sequence shards. Send and receive split sizes follow each rank’s actual shard length, supporting Q/K/V resharding and reverse resharding of the outputs without adding sequence-token padding solely to satisfy equal-length communication.

  • CosyVoice3 Speculative Decoding and DiT Compilation

    PR #9692

    Integrated DSpark speculative decoding into the Talker inference path, using multi-token drafts and batched verification. Enabled torch.compile for the Code2Wav DiT path and integrated the compilation configuration into streaming speech generation.

    In the before/after deployment comparison: audio throughput +100.4%; mean TTFA −51.8%; P99 TTFA −41.6%.

  • Dynamic LoRA Support for Diffusion Models

    PR #758

    Co-developed dynamic LoRA management for diffusion models, contributing approximately 70% of the core code (about 2,700 lines). Added runtime loading, unloading, LRU eviction, linear/QKV injection, and OpenAI-compatible serving support.

    Technical details

    Co-developed the dynamic LoRA adapter management and loading system, contributing approximately 70% of the core code (about 2,700 lines).

    • Adapter lifecycle. Implemented DiffusionLoRAManager with runtime loading, on-demand unloading, and LRU eviction for efficient memory reuse.
    • Layer injection and serving. Implemented diffusion-specific LoRA linear layers and sliced injection for merged QKV layers. Added dynamic adapter selection to the OpenAI-compatible interface and end-to-end numerical-consistency tests for hot loading.

  • Diffusion Model Weight Quantization

    PR #1528

    Integrated bitsandbytes weight quantization through load-time quantization for Hugging Face components and in-place post-load quantization for vLLM Linear weights, with configuration isolation and compatible forward execution.

    Peak memory decreased by approximately 30%, from about 24.5 GiB to 17.1 GiB.

    Technical details

    Integrated bitsandbytes weight quantization through two complementary paths: load-time quantization for Hugging Face components and in-place quantization after loading vLLM Linear weights.

    • Load-time quantization. Intercepted component loading and injected quantization configuration, supporting text encoders and other Hugging Face components while preventing configuration interference between concurrent loads.
    • Post-load quantization. Converted and replaced existing weights in place, integrated forward adapters with quant_method, and preserved layer structure and interfaces while handling shapes, precision, and bias compatibility.

  • Qwen-Image-Edit Modulation Kernel Fusion

    PR #5921

    Developed LayerNorm-select01 and residual-LayerNorm-select01 Triton kernels, fusing parameter selection, scale/shift, and gating to reduce intermediate tensor traffic and kernel launches.

    Up to 5.82× kernel speedup and approximately 9.9% end-to-end performance improvement.

  • Qwen-Image Q/K RMSNorm and RoPE Fusion

    PR #5931

    3.58× kernel speedup and approximately 2.2% end-to-end performance improvement.
